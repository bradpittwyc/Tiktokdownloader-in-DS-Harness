TikTok 下载器

使用方法
1. 双击 TikTokBatchMVP.exe。
2. 粘贴 TikTok 博主主页链接，点「识别」。
3. 勾选想保存的作品，选择保存文件夹，点「开始下载」。

主要功能
- 批量读取博主全部公开作品（视频 + 图文），支持一次粘贴多个博主
- 画质可选：最佳画质 / 1080p / 720p / 540p，默认最高画质，并排除带水印的源
- 本地记录：抓过的博主会存在本机，下次点「最近抓取的博主」直接打开，不再重复抓取
- 追新：只抓博主最新发布的内容，扫到已知作品就停
- 抓取可中断：抓取期间按钮变「暂停抓取」，已抓到的作品会保留
- 后台继续：提示条上的「继续抓取」在后台补齐，不影响当前页面的浏览和下载
- 遇到安全验证时会打开验证窗口；通过后可以直接关掉，软件会在后台接着抓
- 下载队列支持暂停 / 继续 / 取消 / 失败重试 / 清除已完成
- 作品列表可搜索、排序、按日期与数量筛选，可导出 CSV

说明
- 需要电脑已安装 Chrome 或 Edge，抓取复用本机浏览器环境。
- 抓取和图文解析不会弹出可见窗口（浏览器停在屏幕外）。
- 已下载作品会按作品 ID 自动跳过，避免重复下载。
- 原视频有字幕轨时会一并保存，并可据此生成英文学习文档（需自备 API Key）。
- TikTok 会不定期调整页面或限制访问，失败时稍后重试通常即可。
- 请只下载你有权保存和使用的内容。
