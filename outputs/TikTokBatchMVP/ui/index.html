本机数据位置

抓取记录、登录态、缓存与加密后的 API Key 都存在 %LOCALAPPDATA%\TikTokBatchMVP。卸载不会删除这个目录。

TikTok 登录状态在普通 Chrome 中登录后关闭窗口即可保存。抓取复用该浏览器环境；遇到验证时，请从作品列表打开验证窗口。尚未读取登录状态
关于凭据

TikTok 登录态、GitHub Token 与 AI 的 API Key 都用 Windows DPAPI 按当前用户加密，不写进任何设置文件，也不会回传到界面。
