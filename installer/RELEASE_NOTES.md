# TikTok 下载器 v1.5.0

Windows 桌面版 TikTok 批量下载工具。给一个博主主页链接，把 TA 的全部公开作品抓到本地：
按作品 ID 去重、画质可选、支持图文帖与字幕。界面用 pywebview，
抓取用 Playwright 驱动**本机原生 Chrome**，下载用 yt-dlp ——
**全程不需要保持浏览器窗口打开**。

> v1.5.0 是设置页的一次重做，外加一个**安全修复**。

## 相比 v1.4.0 的变化

### 设置页改成了分类

原来是 17 行设置堆在一个弹窗里、一路往下翻。现在左侧是分类导航，右侧是内容：

| 分类 | 里面有什么 |
|---|---|
| **通用** | 视频文件名模板、日期范围、下载数量、下载模式、多博主链接 |
| **外观** | 当前版本只有深色主题，这里说明了后续会开放什么 |
| **AI 大模型** | 提供方、API 地址、模型名、API Key、测试连接、学习文档开关 |
| **存储** | 默认保存目录、同时下载数、失败重试次数、本机数据位置 |
| **账户与登录** | TikTok 登录态、Cookie 来源、cookies.txt、GitHub Token |
| **关于** | 当前版本、检查更新 |

布局照 **Tony Dev Kit 的 SETTINGS_STANDARD**：两列、侧栏定宽 240px、只做导航，
同一时刻只有一个分类可见，标题由面板统一给。
**"上次停在哪个分类"不会被记住** —— 每次打开都回到「通用」。

### 🔒 安全修复：API Key 不再明文存盘

之前 **API Key 是以明文写在 `learning.json` 里的**。现在：

| | 之前 | 现在 |
|---|---|---|
| 存在哪 | 设置文件里的明文字段 | 单独一个文件，用 **Windows DPAPI** 按当前用户加密 |
| 设置文件里 | 明文 | 空 |
| 界面上 | 会被读回显示 | 只显示"已配置"，**永远读不回值** |

三条行为约定：

- **留空 = 不修改**。界面每次都把输入框清空，所以留空不会把你的 Key 抹掉；
  真要清除请点旁边的「清除」按钮。
- **升级时自动迁移**：第一次打开新版会把旧的明文 Key 搬进加密文件，
  并把设置文件里那一格清掉。**你不需要做任何事。**
- **迁移失败时不会丢 Key**：万一加密不可用，程序会保留原样并记日志 ——
  功能照常可用，只是暂时还是明文。宁可这样，也不能因为迁移失败让功能不可用。

## 从旧版本升级

设置 → 软件更新 → 检查更新 → 下载并安装，会自动下载新版安装包并启动安装向导，
同一个 `AppId` 原地升级，**设置、登录态、下载记录都会保留**（API Key 也会自动迁移）。
本仓库已公开，检查更新不需要填写任何 Token。

## 功能

**抓取**
- 批量读取博主全部公开作品（视频 + 图文），支持一次粘贴多个博主
- **本地记录优先** —— 抓过的博主存在本机，点「最近抓取的博主」直接进页面，不再重复抓取
- **追新** —— 只抓最新发布的内容，扫到已知作品就停
- **抓取可中断** —— 抓取期间按钮变「暂停抓取」，已抓到的作品会保留
- **后台继续** —— 归档没抓完时，提示条上的「继续抓取」在后台补齐，不影响当前页面操作
- **安全验证** —— 遇到滑块时打开验证窗口，通过后可直接关闭，软件在后台接着抓

**下载**
- 画质可选：最佳画质 / 1080p / 720p / 540p，默认最高画质，并排除带水印的源
- 并发数可调；队列支持暂停 / 继续 / 取消 / 失败重试 / 清除已完成
- 下载队列一屏 8 个，右下角翻页；左下角可查看下载历史
- 已下载作品按作品 ID 自动跳过；原视频有字幕轨时一并保存
- **每条作品额外存封面、纯音频轨、原始信息快照和素材元数据**

**素材库**
- 扫描本地素材，看清完整性；一键补齐缺失的封面 / 音频 / 原始信息 / 元数据
- 按标题 / 文案 / 话题 / 作者 / **AI 标签**检索，可按播放量、点赞、时长、日期排序与筛选
- **AI 打标签**：给筛出来的素材生成中文内容标签，标签参与检索

**设置**
- **六个分类**：通用 / 外观 / AI 大模型 / 存储 / 账户与登录 / 关于
- AI 提供方可切换（OpenAI / DeepSeek / 自定义 OpenAI 兼容接口）
- **API Key 用 Windows DPAPI 加密，不进设置文件**

**界面**
- 窗口标题栏（含任务栏、Alt+Tab）常显当前版本号
- 作品列表可搜索、排序、按日期与数量筛选；导出 CSV
- 可生成英文学习文档

## 已知限制

- 需要本机装有 Chrome 或 Edge（复用其浏览器环境，不打包浏览器 profile）。
- 自动升级走的是安装版安装包；免安装版用户升级后会被装成安装版。
- 补齐只能补**有抓取记录**的博主；记录被清掉的补不了。
- 补齐是**按博主整批**做的（跳过已经补好的），不是只补搜索结果里那几条。
- **打标签必须先补齐**：没有 `meta.json` 就没有标题和文案，这类素材会被跳过。
- 打标签需要自备 API Key，要花钱（一条素材一次调用）。
- 加密的凭据**换台电脑或换个 Windows 用户就读不出来**（这是 DPAPI 的设计），
  需要重新填一次。
- 「外观」分类目前是空的 —— 只有深色主题，里面写明了后续会开放什么。
- 图文帖不单独存音频轨（第一张图就是它的封面）。
- 卸载前请先关闭程序 —— 程序还开着时 Windows 删不掉正在运行的 EXE，
  会在安装目录留下一个残留文件（注册表和开始菜单仍会正常清理）。
- 卸载不会删除 `%LOCALAPPDATA%\TikTokBatchMVP` 下的用户数据
  （抓取记录、登录态、加密的 Key、浏览器 profile），需要的话请手动清理。
- 真实的滑块验证无法自动化，需要人工过一次。
