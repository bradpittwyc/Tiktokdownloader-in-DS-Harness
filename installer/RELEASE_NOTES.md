# TikTok 下载器 v1.2.0

Windows 桌面版 TikTok 批量下载工具。给一个博主主页链接，把 TA 的全部公开作品抓到本地：
按作品 ID 去重、画质可选、支持图文帖与字幕。界面用 pywebview，
抓取用 Playwright 驱动**本机原生 Chrome**，下载用 yt-dlp ——
**全程不需要保持浏览器窗口打开**。

> v1.1.0 起开始做「**视频素材 + 学习内容工厂**」。
> v1.1.0 让新下载的作品带齐原料，v1.2.0 把**已经下过的老作品**也补上，
> 并加了一个能看清本地素材状况的入口。

## 相比 v1.1.0 的变化

**新增「素材库」**（顶栏 🗂 素材库）：选一个保存目录 → 扫描 → 看清本地有多少素材、
每条缺哪些文件 → 一键补齐。

- **扫描是纯本地操作**，不联网、不上传任何东西，几秒钟出结果
- 摘要会告诉你：共多少条素材、完整多少条、待补多少条、视频/图文各多少
- 待补列表逐条列出缺什么（封面 / 音频 / 原始信息 / 元数据）
- **补齐会联网**重新读取每条作品的信息，把缺的文件补上；可以随时停止

⚠️ **补齐需要先打开一个博主**。因为文件名里没有作品 ID（默认命名模板不含它），
光看文件推不出 TikTok 链接 —— 软件是拿**本机保存的抓取记录**去对的。
没有记录时会如实告诉你补不了，不会瞎猜。

## 从旧版本升级

设置 → 软件更新 → 检查更新 → 下载并安装，会自动下载新版安装包并启动安装向导，
同一个 `AppId` 原地升级，**设置、登录态、下载记录都会保留**。
本仓库已公开，检查更新不需要填写任何 Token。

## 功能

**抓取**
- 批量读取博主全部公开作品（视频 + 图文），支持一次粘贴多个博主
- **本地记录优先** —— 抓过的博主存在本机，点「最近抓取的博主」直接进页面，不再重复抓取
- **追新** —— 只抓最新发布的内容，扫到已知作品就停
- **抓取可中断** —— 抓取期间按钮变「暂停抓取」，已抓到的作品会保留
- **后台继续** —— 归档没抓完时，提示条上的「继续抓取」在后台补齐，不影响当前页面操作
- **安全验证** —— 遇到滑块时打开验证窗口，通过后可直接关闭，软件在后台接着抓

**下载**
- 画质可选：最佳画质 / 1080p / 720p / 540p，默认最高画质，并排除带水印的源
- 并发数可调；队列支持暂停 / 继续 / 取消 / 失败重试 / 清除已完成
- 下载队列一屏 8 个，右下角翻页；左下角可查看下载历史
- 已下载作品按作品 ID 自动跳过；原视频有字幕轨时一并保存
- **每条作品额外存封面、纯音频轨、原始信息快照和素材元数据**

**素材库**
- 扫描本地素材，看清完整性；一键补齐缺失的封面 / 音频 / 原始信息 / 元数据
- 扫描不联网；补齐联网但可随时停止

**界面**
- 窗口标题栏（含任务栏、Alt+Tab）常显当前版本号
- 作品列表可搜索、排序、按日期与数量筛选；导出 CSV
- 可生成英文学习文档（需自备 API Key）

## 已知限制

- 需要本机装有 Chrome 或 Edge（复用其浏览器环境，不打包浏览器 profile）。
- 自动升级走的是安装版安装包；免安装版用户升级后会被装成安装版。
- 补齐只能补**有抓取记录**的博主；记录被清掉的补不了。
- 图文帖不单独存音频轨（第一张图就是它的封面）。
- 卸载前请先关闭程序 —— 程序还开着时 Windows 删不掉正在运行的 EXE，
  会在安装目录留下一个残留文件（注册表和开始菜单仍会正常清理）。
- 卸载不会删除 `%LOCALAPPDATA%\TikTokBatchMVP` 下的用户数据
  （抓取记录、登录态、GitHub Token、浏览器 profile），需要的话请手动清理。
- 真实的滑块验证无法自动化，需要人工过一次。
