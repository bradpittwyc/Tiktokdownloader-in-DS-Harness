# TikTok 下载器 v1.1.0

Windows 桌面版 TikTok 批量下载工具。给一个博主主页链接，把 TA 的全部公开作品抓到本地：
按作品 ID 去重、画质可选、支持图文帖与字幕。界面用 pywebview，
抓取用 Playwright 驱动**本机原生 Chrome**，下载用 yt-dlp ——
**全程不需要保持浏览器窗口打开**。

> v1.1.0 起开始做「**视频素材 + 学习内容工厂**」。这一步先把原料备齐：
> 每条作品除了视频和字幕，还会自动存下封面、音频轨和一份机器可读的元数据。

## 相比 v1.0.5 的变化

**每个作品现在落这些文件**（同一个文件名前缀）：

| 文件 | 内容 |
|---|---|
| `<名>.mp4` | 视频 |
| `<名>.<语言>.vtt` | 字幕 |
| `<名>.cover.jpg` | **封面图** |
| `<名>.audio.mp3` | **纯音频轨**（提取音频不需要额外装任何东西） |
| `<名>.info.json` | 下载时抓到的完整信息快照 |
| `<名>.meta.json` | **素材元数据**：标题、作者、发布时间、时长、分辨率、话题标签、播放/点赞/评论/转发/收藏、配乐，以及上面这些文件的对应关系 |

这份 `meta.json` 是给下一步的素材库和自动打标签用的，结构固定、字段名稳定。

**安全修复**：抓取到的原始信息里**带着你的登录 Cookie**。
原样落盘等于把账号凭证写进视频文件夹 —— 那是会被同步、备份、发给别人的目录。
现在落盘前会强制剔除 `cookies` 与 `http_headers`。实测确认过：连匿名请求拿到的
信息里都有 `ttwid`，注入登录态后更会带上 `sessionid`。

**修复元数据被抹掉**：补全作品数据（播放量、点赞数那一步）时会把本机的博主归档
整个覆盖，导致"是否抓全过""上次同步时间"这些记录丢失。已经装了旧版的用户，
本机归档里这些字段**可能已经是缺的**，重新抓取一次即可补回。

**修复下载跳过判断**：原先如果作品的封面或元数据文件先存在，会被误判成
"这条已经下载过"而跳过 —— 现在不会了。

## 下载

| 文件 | 说明 |
|---|---|
| `TikTokBatchMVP.exe` | **免安装版**，单文件，双击即用 |
| `TikTokBatchMVP-Setup-1.1.0.exe` | **安装版**，建议用这个（自动升级依赖它） |

两个版本功能完全一致。需要本机已安装 **Chrome 或 Edge**。

## 从旧版本升级

设置 → 软件更新 → 检查更新 → 下载并安装，会自动下载新版安装包并启动安装向导，
同一个 `AppId` 原地升级，**设置、登录态、下载记录都会保留**。
本仓库已公开，检查更新不需要填写任何 Token。

⚠️ **已经下载过的老作品不会自动补这几样新文件** —— 下载前的跳过判断是纯跳过，
补齐入口在下一步做。

## 功能

**抓取**
- 批量读取博主全部公开作品（视频 + 图文），支持一次粘贴多个博主
- **本地记录优先** —— 抓过的博主存在本机，点「最近抓取的博主」直接进页面，不再重复抓取
- **追新** —— 只抓最新发布的内容，扫到已知作品就停
- **抓取可中断** —— 抓取期间按钮变「暂停抓取」，已抓到的作品会保留
- **后台继续** —— 归档没抓完时，提示条上的「继续抓取」在后台补齐，不影响当前页面操作
- **安全验证** —— 遇到滑块时打开验证窗口，通过后可直接关闭，软件在后台接着抓

**下载**
- 画质可选：最佳画质 / 1080p / 720p / 540p，默认最高画质，并排除带水印的源
- 并发数可调；队列支持暂停 / 继续 / 取消 / 失败重试 / 清除已完成
- 下载队列一屏 8 个，右下角翻页；左下角可查看下载历史
- 已下载作品按作品 ID 自动跳过；原视频有字幕轨时一并保存
- **每条作品额外存封面、纯音频轨、原始信息快照和素材元数据**（v1.1.0 起）

**界面**
- 窗口标题栏（含任务栏、Alt+Tab）常显当前版本号
- 作品列表可搜索、排序、按日期与数量筛选；导出 CSV
- 可生成英文学习文档（需自备 API Key）

## 已知限制

- 需要本机装有 Chrome 或 Edge（复用其浏览器环境，不打包浏览器 profile）。
- 自动升级走的是安装版安装包；免安装版用户升级后会被装成安装版。
- 卸载前请先关闭程序 —— 程序还开着时 Windows 删不掉正在运行的 EXE，
  会在安装目录留下一个残留文件（注册表和开始菜单仍会正常清理）。
- 卸载不会删除 `%LOCALAPPDATA%\TikTokBatchMVP` 下的用户数据
  （抓取记录、登录态、GitHub Token、浏览器 profile），需要的话请手动清理。
- 真实的滑块验证无法自动化，需要人工过一次。
