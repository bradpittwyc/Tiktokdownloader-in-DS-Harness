# TikTok 下载器 v1.0.0

Windows 桌面版 TikTok 批量下载工具的第一个正式版本。

给一个博主主页链接，把 TA 的全部公开作品抓到本地：按作品 ID 去重、画质可选、
支持图文帖与字幕。界面用 pywebview，抓取用 Playwright 驱动**本机原生 Chrome**，
下载用 yt-dlp —— **全程不需要保持浏览器窗口打开**。

## 下载

| 文件 | 说明 |
|---|---|
| `TikTokBatchMVP.exe` | **免安装版**，单文件，双击即用 |
| `TikTokBatchMVP-Setup-1.0.0.exe` | **安装版**，带开始菜单与桌面快捷方式，可卸载 |

两个版本功能完全一致，按喜好选一个即可。需要本机已安装 **Chrome 或 Edge**。

## 主要功能

**抓取**
- 批量读取博主全部公开作品（视频 + 图文），支持一次粘贴多个博主
- **本地记录优先** —— 抓过的博主存在本机，点「最近抓取的博主」直接进页面，不再重复抓取
- **追新** —— 只抓最新发布的内容，扫到已知作品就停
- **抓取可中断** —— 抓取期间按钮变「暂停抓取」，已抓到的作品会保留
- **后台继续** —— 归档没抓完时，提示条上的「继续抓取」在后台补齐，不影响当前页面操作
- **安全验证** —— 遇到滑块时打开验证窗口，通过后可直接关闭，软件在后台接着抓

**下载**
- 画质可选：最佳画质 / 1080p / 720p / 540p，默认最高画质，并排除带水印的源
- 并发数可调；队列支持暂停 / 继续 / 取消 / 失败重试 / 清除已完成
- 已下载作品按作品 ID 自动跳过
- 原视频有字幕轨时一并保存

**界面**
- 作品列表可搜索、排序、按日期与数量筛选
- 导出 CSV
- 可生成英文学习文档（需自备 API Key）

## 这一版修掉的关键问题

- **「抓不全」**：抓取改用「原生 Chrome + CDP」。
  Playwright 自己启动的浏览器会被 TikTok 的 WAF 识别并返回拦截页 ——
  用 `subprocess` 起真 Chrome 再挂上去就不会。这也是之前只有验证窗口能抓到东西的原因。
- **验证窗口必须一直开着**：关掉后会自动转后台继续，不需要守着窗口。
- **`下载器未生成目标文件`**：文件其实下好了却认不出来。
  根因是 app 按本地时间算上传日期、yt-dlp 按 UTC，晚上上传的视频差一天。
- **设置每次启动都重置**：pywebview 的 `private_mode` 默认开着，
  导致默认保存目录等所有偏好都不落盘。
- **状态栏残留「后台读取数据 N/M」**：补全结束没有终点信号。

## 已知限制

- 需要本机装有 Chrome 或 Edge（复用其浏览器环境，不打包浏览器 profile）。
- TikTok 会不定期调整页面或限制访问，失败时稍后重试通常即可。
- 真实的滑块验证无法自动化，需要人工过一次。
