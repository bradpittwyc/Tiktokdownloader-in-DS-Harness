# TikTok 下载器 v1.0.1

Windows 桌面版 TikTok 批量下载工具。给一个博主主页链接，把 TA 的全部公开作品抓到本地：
按作品 ID 去重、画质可选、支持图文帖与字幕。界面用 pywebview，
抓取用 Playwright 驱动**本机原生 Chrome**，下载用 yt-dlp ——
**全程不需要保持浏览器窗口打开**。

## 相比 v1.0.0 的变化

- **图标换成 TikTok logo** —— 窗口标题栏与任务栏不再是 Python 图标。
  pywebview 在 Windows 上不处理 `icon` 参数（文档写明只支持 GTK/QT），
  现在改为运行时给真实窗口设置，源码运行与打包运行都覆盖。
- **下载队列分页** —— 一屏 8 个，右下角 `‹ n/m ›` 翻页。
  以前勾选几十个会拖成一条很长的列表。
- **下载历史** —— 队列左下角新增入口，按作品新旧列出本机所有下载记录，
  带状态与保存文件夹，可直接打开对应目录。

## 功能

**抓取**
- 批量读取博主全部公开作品（视频 + 图文），支持一次粘贴多个博主
- **本地记录优先** —— 抓过的博主存在本机，点「最近抓取的博主」直接进页面，不再重复抓取
- **追新** —— 只抓最新发布的内容，扫到已知作品就停
- **抓取可中断** —— 抓取期间按钮变「暂停抓取」，已抓到的作品会保留
- **后台继续** —— 归档没抓完时，提示条上的「继续抓取」在后台补齐，不影响当前页面操作
- **安全验证** —— 遇到滑块时打开验证窗口，通过后可直接关闭，软件在后台接着抓

**下载**
- 画质可选：最佳画质 / 1080p / 720p / 540p，默认最高画质，并排除带水印的源
- 并发数可调；队列支持暂停 / 继续 / 取消 / 失败重试 / 清除已完成
- 已下载作品按作品 ID 自动跳过，避免重复下载
- 原视频有字幕轨时一并保存

**界面**
- 作品列表可搜索、排序、按日期与数量筛选
- 导出 CSV
- 可生成英文学习文档（需自备 API Key）

## 已知限制

- 需要本机装有 Chrome 或 Edge（复用其浏览器环境，不打包浏览器 profile）。
- TikTok 会不定期调整页面或限制访问，失败时稍后重试通常即可。
- 真实的滑块验证无法自动化，需要人工过一次。
